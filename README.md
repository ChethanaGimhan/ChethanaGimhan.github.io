# Chethana Gimhan — Personal Site

The source of my personal site, served with GitHub Pages at **https://chethanagimhan.github.io/**.

I'm a Computer Science & Engineering undergraduate at the University of Moratuwa, specializing in Cyber Security, with a focus on DevOps and platform engineering. The site is a single, fast page: about, selected projects, tech stack, credentials and contact details. For deeper project write-ups, see my portfolio at [chethanagimhan.cse23.org](https://chethanagimhan.cse23.org).

## What's in this repo

| File | Purpose |
| --- | --- |
| `index.html` | The whole site: HTML, CSS and structured data in one file, with no build step |
| `robots.txt` | Tells search engines they may crawl the site and where the sitemap is |
| `sitemap.xml` | Lists the site's pages for Google Search Console |

## Design notes

- Plain HTML and CSS, no framework and no JavaScript
- Follows the system light/dark theme
- Respects `prefers-reduced-motion`
- Keyboard navigable, with a skip link and visible focus states
- Search-ready: canonical URL, Open Graph tags, and `Person` structured data (JSON-LD)

## Run locally

Open `index.html` in a browser. There is nothing to install.
